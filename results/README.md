# Verified aggregate results

The CSV files in this directory preserve the aggregate values reported in the project README.

| File | Contents |
|---|---|
| `benchmark_summary.csv` | Representative FUNSD and CORD v2 confidence/embedding comparisons |
| `critical_field_summary.csv` | CORD critical-field omission, substitution, and value-shift analyses |

These tables are curated aggregates from completed experiment artifacts. The public repository does not include the original corpus, case-level OCR outputs, corruption harness, or raw predictions. The CLI under `src/ocr_embedding_monitor/` demonstrates the monitoring interface but does not reproduce these benchmark values.
